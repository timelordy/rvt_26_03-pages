# Иллюстрации первых двух пар

Пометки со стрелками рисуются поверх изображений на сайте. По клику открывается исходное изображение без пометок.

## Фрагменты существующих изображений

`wall-command.png`, `quick-access.png`, `view-cube.png`, `view-controls.png`, `selection-controls.png`, `selected-wall.png` вырезаны из существующего `interface.png`. Для узких панелей добавлены белые поля, чтобы стрелки не закрывали кнопки. Содержимое интерфейса не перерисовывалось.

`interface.png`, `browser.png`, `properties.png`, `revit-3d-example.png`, `revit-home-2024.png` уже были в проекте. Их исходные файлы сохранены. Они не являются снимками, сделанными на локальном компьютере в ходе этого изменения.

## Учебный перевод

Файлы `*-ru.png` содержат русские подписи, наложенные поверх английских фоном в цвет интерфейса. Старые розовые отметки убраны из учебной версии; в `interface-ru.png` также обрезана верхняя дублирующая схема ленты. Имена файлов, обозначения и числовые значения не переводятся.

Кнопка «Открыть крупно» открывает учебную версию без стрелок сайта. Ссылка «Исходник без перевода» ведёт к сохранённому оригиналу. Это учебная редактура изображения, а не снимок русской установки Revit.
